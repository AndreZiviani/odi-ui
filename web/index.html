    Loading a new image
    
    
    Uploading is still a shell job — the image is about
       3 MB and this daemon would have to hold it in memory the device does
       not have. Build it, copy it over, check it arrived intact, then write it
       to the partition you are not running:
    

    
    
    Then come back here and press Try on that partition. Do not
       reach for Keep first: the whole value of the trial is that the stick
       recovers on its own if the image is bad.
    
    
    /tmp is a RAM disk sharing
       27 MB with everything else running, so the
       copy is tight but fits — the page cache gives way. The updater
       checks the md5 of both the kernel and the root filesystem before it
       erases anything, and streams each straight to flash, so it needs no
       scratch space beyond the tarball itself.
    

    
    What the OLT is told
    
    
    The version beside each partition is what the updater wrote
       from that image. It is not automatically what your ISP sees: on
       this base, chk_swver_fix.sh copies it into
       OMCI_SW_VER1/2 at every boot, but only when
       OMCI_OLT_MODE is neither 0 nor 21. Setting
       sw_custom_version0 or sw_custom_version1 in the
       U‑Boot environment makes the script prefer that string instead, and
       it survives reflashing — which is the supported answer to
       “my OMCI software version resets at every boot”. The widely
       repeated answer, OMCI_OLT_MODE=21, is one that script’s
       own comment calls a hack that segfaults checkomci.
    
    
    Nothing here writes it. Changing the version an ISP
       authenticates against is a decision to make deliberately, from a shell,
       on a line you can afford to lose:
       nv setenv sw_custom_version0 <string>.
    

    
    How a trial boot works
    
    
    Trying a partition boots it once, with the
       hardware watchdog armed. If the image does not come up, the stick returns
       by itself to whichever partition is kept — no console, no
       intervention. A trial that boots fine still reverts on the next reboot,
       so keeping it is a separate decision you make after seeing it work.
